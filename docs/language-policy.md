# Language Policy

DQ QuestionBank Core uses English as the single normative language for its
public API names, command-line interface, browser playground, documentation,
issue templates, release notes, and repository-maintained Wiki pages.

This policy keeps the public contract reviewable and prevents parallel,
inconsistent documentation from becoming competing specifications. It does not
limit the canonical question model: question content, metadata, and imported
documents may use any language supported by the schema.

Community translations are welcome as independently maintained material that
links back to the English source. A translation must clearly identify its
upstream version and must not replace, silently alter, or become a second
normative copy of the English public contract.
