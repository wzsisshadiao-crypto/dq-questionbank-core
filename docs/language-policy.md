# Language Policy

DQ QuestionBank Core uses English as the single normative language for its
public API names, command-line interface, browser playground, technical documentation,
issue templates, release notes, and repository-maintained Wiki pages.

This policy keeps the public contract reviewable and prevents parallel,
inconsistent documentation from becoming competing specifications. It does not
limit the canonical question model: question content, metadata, and imported
documents may use any language supported by the schema.

The repository may maintain localized product introductions and quick-start
pages, including English and Simplified Chinese website entry points. These
pages explain the product and link back to the English technical contract; they
do not redefine API names, schemas, compatibility promises, contribution rules,
or release semantics.

Community translations are welcome when they identify their English upstream
version and do not replace, silently alter, or become a second normative copy of
the English public contract.
