# FAQ

## Does the repository contain real exam questions?

No. Examples and tests must be synthetic, public-domain, original, or clearly
licensed. Do not open a public issue with private, personal, or copyrighted
question-bank data.

## Which languages are supported?

The schema can carry multilingual question content. Public API names, CLI
messages, docs, and maintained Wiki pages are English-only; see the
[language policy](../language-policy.md).

## How do I report a security problem?

Follow [SECURITY.md](../../SECURITY.md) and use a private reporting channel.
