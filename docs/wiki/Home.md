# Welcome to the DQ QuestionBank Core Wiki

The repository directory `docs/wiki/` is the only editable source for these
Wiki pages. The `dq-wiki-local` and `dq-wiki-export` repositories are rendered
targets; use `python scripts/wiki_sync.py check`, `export`, or `sync` rather
than editing either target directly.

browser playground for importing, validating, converting, and exchanging
structured educational questions. It is licensed under Apache 2.0.
