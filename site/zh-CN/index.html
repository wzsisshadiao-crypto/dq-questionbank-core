一道题的完整生命周期

题目通过明确、可复核的阶段逐步进入题库。原始依据、中间结果和人工判断不会被隐藏在一次不可解释的导入操作之后。

  1. 01导入接入 JSON、Markdown、LaTeX、DOCX，或针对特定文档设计导入流程。
  2. 02结构化统一整理题干、公式、表格、选项、答案、解析和元数据。
  3. 03人工核对在候选题进入正式题库前检查来源、字段和修正建议。
  4. 04编辑与质检按字段修改题目，再运行确定性的本地质量检查。
  5. 05组卷与导出将题目编排成试卷，导出规范 JSON 或常规 DOCX。

成熟工作界面，稳定公共内核

可下载的可视化应用与 Python 公共接口共享同一套规范题目模型。普通用户可以直接操作，贡献者则可以扩展格式、存储和工作流。

面向日常题目工作

题库、编辑、组卷、导入、数据和质检中心，支持离线 KaTeX、结构化表格以及答案与解析。

可替换的扩展边界

规范 Schema、格式注册表、插件发现、存储适配器、兼容 fixtures 和稳定公共 API。

先核对，再持久化

AI 与后续文档流水线只产生可审阅候选结果；仓库不捆绑密钥，也不允许静默写入生产题库。

可视化快速开始

一条命令打开公开题库。

只需要 Python 3.10 或更新版本。服务仅绑定本机回环地址，创建被 Git 忽略的本地工作区，并打开经过审查的合成案例。

上方实景图展示仓库所有者批准公开的示例题 DX_SX_154；公开仓库不附带生产数据库、其他私有题目、私有纠错规则、密钥、供应商配置或维护记录。 

git clone https://github.com/wzsisshadiao-crypto/dq-questionbank-core.git
cd dq-questionbank-core
python run.py
