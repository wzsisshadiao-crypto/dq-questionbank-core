# 2020 Pascal Contest licensed sample

This directory contains exactly three short, text-only questions selected from
the official 2020 Pascal Contest: Questions 2, 3, and 6. It exists to exercise
the canonical question schema with a small real-world, openly licensed data
set; it is not a general exam archive.

## Source and provenance

- Publisher: Centre for Education in Mathematics and Computing (CEMC),
  University of Waterloo
- Contest: 2020 Pascal Contest (Grade 9)
- Official HTML: https://cemc.uwaterloo.ca/sites/default/files/documents/2020/2020PascalContest.html
- Official PDF: https://cemc.uwaterloo.ca/sites/default/files/documents/2020/2020PascalContest.pdf
- Source PDF SHA-256: `2553dadf296212d0aea2c49b53264ef448addba5b10cc06ec4d4cc04e36e799e`
- Retrieved and visually checked: 2026-10-20
- Included locators: Questions 2, 3, and 6
- License: CC BY-NC 4.0; see [`LICENSE.md`](LICENSE.md)

The source PDF was read and visually checked against the HTML version. The
question wording and choice order were retained, while mathematical notation
was represented as canonical LaTeX blocks. Answer letters were independently
checked; official solution prose was not copied. The source PDF itself and all
CEMC logos are intentionally excluded.
